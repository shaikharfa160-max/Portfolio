# Shaikh Arfa – Portfolio (React)

Built with React (functional components, props, useState, useEffect) and plain CSS. No extra libraries.

## Run
```
npm install
npm run dev
```
Open the link shown in the terminal (usually http://localhost:5173).

## Change your details
Open `src/data/portfolio.js`. Your name, links, skills, projects and about text are all there.
- To show a "Live demo" button on a project, write its link in `live: ""`.
- Your resume PDF is in `public/Arfa_Resume.pdf` (replace it when you update your resume).

## Build for deployment
```
npm run build
```
Upload the `dist` folder to Vercel or Netlify.
